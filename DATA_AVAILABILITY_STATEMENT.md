# Data And Code Availability

This study uses publicly available bibliographic records from PubMed, PubMed/PubTator-derived annotations and publicly available drug-reference resources described in the Methods.

This repository contains analysis code, plotting scripts, methods documentation, metric definitions and the final eight-mode manifest. The atlas is restricted to ferroptosis, pyroptosis, necroptosis, NETosis, immunogenic cell death, cuproptosis, PANoptosis and disulfidptosis.

Large raw and intermediate PMID-level context tables, PubMed/PubTator intermediate outputs, drug-reference mapping tables and figure source-data bundles are not stored in Git because of file-size and database-snapshot constraints.

No individual-level participant data or newly generated human-subject data were used in this study.
