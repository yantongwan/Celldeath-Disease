# Data Availability Statement

## Nature-Style Draft

The bibliographic and text-mining analyses in this study were based on publicly available records from PubMed and PubMed/PubTator-derived annotations, together with publicly available drug-reference resources where indicated in the Methods. The curated PMID-level source tables, figure source data, and scripts required to reproduce the analyses will be deposited in GitHub and an archival data repository before publication: GitHub, `[repository URL]`; Zenodo/figshare/OSF, `[DOI]`. The atlas was restricted to eight selected regulated cell death modes: ferroptosis, pyroptosis, necroptosis, NETosis, immunogenic cell death, cuproptosis, PANoptosis, and disulfidptosis. Large raw and intermediate PubMed/PubTator context tables are provided in the archival dataset rather than the GitHub repository because of file-size constraints. No individual-level participant data or newly generated human-subject data were used in this study.

## Code Availability Draft

All analysis and plotting scripts used to generate the figures and source tables are available at `[GitHub repository URL]` and will be archived with a permanent DOI at `[Zenodo/figshare/OSF DOI]`. Scripts requiring PubMed/NCBI access use user-supplied environment variables for email and API-key configuration; no private credentials are included in the repository.

## Repository Placement Recommendation

- GitHub: code, lightweight manifests, figure metric documentation, and small source tables.
- DOI archive: raw PMID lists, PMID-level context tables, PubMed/PubTator intermediate outputs, large drug-reference tables, and final source-data bundles.
- Manuscript supplement: final source-data tables needed for direct figure inspection, if requested by the journal.
